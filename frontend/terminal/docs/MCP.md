# MCP 外部工具

MCP 用于把外部工具或数据服务接入当前工作区。接入后，模型可能看到服务声明的工具和返回结果，因此应把每个 MCP 服务视为独立的外部边界。

## 接入前检查

- 服务来源是否可信；
- 会访问哪些文件、网络和账户；
- 是否会写入或删除数据；
- 凭据如何保存、轮换和撤销；
- 是否应该只对某个项目启用。

## 配置思路

MCP 服务通常包含名称、启动方式或地址、参数和环境变量。凭据应通过安全的环境变量或本机凭据配置提供，不要把真实值写进项目提交。

```json
{
  "mcpServers": {
    "example": {
      "command": "example-server",
      "args": ["--stdio"]
    }
  }
}
```

具体字段以服务本身和当前版本的设置界面为准。

## 运行边界

- 未启用的服务不会参与当前会话。
- 工具调用仍受当前权限和人工确认策略约束。
- 服务返回的数据会进入当前上下文，可能影响后续模型请求。
- 服务进程的网络和文件权限还受操作系统与其自身配置影响。

出现工具列表为空、启动失败或调用超时时，先检查程序是否可执行、参数是否正确、网络地址是否可达，以及当前项目是否允许使用该服务。
