# 常用快捷键

终端界面支持键盘导航。不同平台和终端模拟器可能占用部分组合键；界面底部提示和命令面板是当前版本的最终说明。

## 会话操作

| 操作 | 快捷键 |
| --- | --- |
| 打开命令面板 | `Ctrl+K` |
| 发送消息 | `Enter` |
| 输入多行内容 | `Shift+Enter` |
| 中止当前生成 | `Esc` |
| 滚动历史 | `PageUp` / `PageDown` |
| 退出当前界面 | `Ctrl+C` |

## 使用建议

- 在命令面板中搜索设置、模型、会话和扩展操作。
- 需要确认高影响工具调用时，先阅读目标路径、命令和网络地址。
- 终端较窄时优先使用命令面板，避免依赖被截断的状态文字。
