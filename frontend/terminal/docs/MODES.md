# 运行模式

运行模式决定任务节奏、工具确认频率和输出侧重点。它不会替代权限策略；高影响动作仍可能要求人工确认。

## 常用模式

| 模式 | 适合场景 | 特点 |
| --- | --- | --- |
| Plan | 先分析再行动 | 重点输出步骤、风险和待确认项 |
| Work | 日常项目工作 | 在解释和执行之间保持平衡 |
| Operate | 已明确的重复任务 | 减少中间展示，仍遵循权限边界 |

模式选择影响交互体验，不会改变模型服务商、工作区范围或操作系统权限。

## 如何选择

- 需求不清楚、影响范围较大时使用 Plan。
- 需要边看边改项目时使用 Work。
- 输入、目标和回滚方式都明确时使用 Operate。

无论模式如何，涉及删除、发布、外部网络或远程主机的操作都应先确认目标和范围。
