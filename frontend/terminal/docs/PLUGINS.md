# 扩展包

扩展包可以组合 Skills、命令、工具声明和参考资源。它们比单个 Skill 影响范围更大，因此安装、启用和更新都应经过审查。

## 推荐流程

1. 从可信来源获取扩展包。
2. 查看名称、来源、包含的文件和声明的能力。
3. 保持停用状态完成初步检查。
4. 只在需要的项目中启用。
5. 更新后重新审查内容和权限。

扩展包不等于官方组件。远程压缩包、本地文件夹和项目中已有的扩展都可能包含脚本或外部服务配置。

## 安全边界

- 不要把真实凭据放进扩展包。
- 启用扩展不会绕过文件、命令、网络和人工确认规则。
- 扩展声明的外部服务可能接收当前上下文或工具结果。
- 删除前先停用，并确认不会影响仍需恢复的会话。
