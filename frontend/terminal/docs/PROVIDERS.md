# 模型服务商

终端程序把“服务商”“模型”和“接口地址”分开管理。这样可以在同一套工作区中切换云端模型、本地模型和兼容服务，而不必改变项目文件。

## 服务商类型

- **内置服务商**：应用提供名称、认证方式和常用地址提示。
- **兼容服务商**：填写兼容协议的地址、模型名和 API Key。
- **本地服务**：连接本机或局域网内运行的模型服务。

内置目录会随版本更新。界面中的服务商列表是当前版本可用项的权威来源。

## 配置示例

```toml
provider = "custom"
model = "your-model"
base_url = "https://api.example.com/v1"

[providers.custom]
api_key = "YOUR_API_KEY"
```

本地服务通常使用类似下面的地址：

```text
http://127.0.0.1:11434/v1
```

实际地址和模型名以本地服务的说明为准。

## 选择模型

模型名称不是服务商名称。请求会先根据服务商选择连接方式，再把模型名称交给该服务商。切换模型前确认：

- 模型是否支持对话或工具调用；
- 上下文长度是否满足当前项目；
- 账户是否有访问权限；
- 服务商是否对输入、输出和速率另有限制。

## 连接失败

常见原因包括地址路径错误、Key 失效、模型未开放、区域限制、网络代理和协议不兼容。先用最小消息测试，再逐项增加工具或较长上下文，不要直接把完整项目内容用于排错。

## 隐私提示

选择云端服务时，请阅读服务商的数据处理规则。自定义服务地址可能把请求发送到第三方网关；本地地址也可能指向局域网内的其他设备。
