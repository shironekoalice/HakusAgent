# 终端配置

终端程序使用配置文件、环境变量和启动参数共同决定运行方式。启动参数优先级最高；没有显式设置时，使用本机配置和默认值。

## 模型配置

最小配置只需要服务商、模型和凭据：

```toml
provider = "custom"
model = "your-model"
base_url = "https://api.example.com/v1"

[providers.custom]
api_key = "YOUR_API_KEY"
```

也可以只在当前 shell 中提供凭据：

```text
HAKUS_PROVIDER=custom
HAKUS_MODEL=your-model
HAKUS_BASE_URL=https://api.example.com/v1
```

具体服务商的环境变量和协议差异见[模型服务商](PROVIDERS.md)。

## 配置原则

- 凭据优先通过系统凭据管理或环境变量提供。
- 配置文件中的密钥不要提交到仓库、截图或日志。
- `base_url` 应指向模型接口兼容地址，不要填写管理后台地址。
- 一个项目可以使用项目范围设置，但项目范围设置不应包含个人凭据。

## 工作区与数据

工作区决定文件工具默认看到的范围。用户数据、项目数据和远程连接数据分开管理；更换工作区不会自动复制或上传原项目文件。

可以使用独立数据目录来隔离个人配置、测试配置和便携环境。移动配置时，同时检查扩展、MCP 和远程连接中的地址与权限。

## 运行安全

配置中的权限模式会影响命令、文件和网络工具。它不会改变操作系统权限，也不会让扩展自动获得访问权。详细规则见[权限与安全](SANDBOX.md)。

## 无法连接时

按顺序检查：

1. 服务商名称和模型名称是否正确。
2. 地址是否包含正确的协议路径。
3. API Key 是否有效且有对应模型权限。
4. 当前网络是否能访问该地址。
5. 服务商是否使用特殊的区域、请求头或协议格式。
