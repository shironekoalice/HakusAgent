# 项目总览

HakusAI 是一个本地优先的 AI 工作台。它把模型对话、项目文件、工具权限和可复用流程放在同一套工作区模型下，既可以通过桌面应用使用，也可以在终端中运行。

## 产品形态

### 桌面应用

适合日常项目工作。桌面端包含项目管理、对话、设置、流程画布、变更审阅、语音和更新能力。新建项目时，可以选择本地文件夹，或通过远程连接向导打开 SSH、WSL、Docker 工作区。

### 终端程序

适合服务器、开发板、脚本和偏好键盘操作的场景。终端入口与桌面端共享核心会话、模型、工具和权限概念，但界面和启动方式独立。

### Android / Termux

提供面向 Android arm64 的终端使用方式。Termux 的文件权限、网络权限和系统隔离仍由 Android 与 Termux 决定，应用自身的审批规则不能扩大系统权限。

## 一次任务如何运行

```text
用户请求
   │
   ▼
会话与项目工作区
   │
   ├── 模型推理
   ├── 文件 / 命令 / 网络工具
   ├── Skills / MCP 扩展
   └── 人工确认与运行记录
   │
   ▼
增量结果、变更审阅与可恢复历史
```

运行时会把一次任务拆成连续的事件：消息、工具调用、审批、结果、错误和完成状态。界面据此更新，而不是等待整段文本生成后再一次性刷新。长任务可以暂停，重新打开项目后继续查看历史和状态。

## 工作区边界

- 本地项目以用户选择的文件夹为边界。
- 远程项目以连接配置指定的主机、容器或发行版为边界。
- 文件工具和命令工具遵循当前权限策略；模型本身不能直接绕过这些策略。
- 流程画布中的节点共享当前项目上下文，也可以显式配置输入、输出和人工确认点。

## 数据归属

应用数据分成三类：

1. **用户数据**：会话、偏好、模型配置和扩展状态，默认写入本机用户数据目录。
2. **项目数据**：项目文件和项目范围的扩展配置，留在项目或远程工作区内。
3. **服务数据**：发送给模型服务、MCP 服务或远程主机的数据，由对应服务的策略决定。

本地优先不等于所有请求都离线。选择云端模型时，消息和必要的上下文会发送到该服务商；选择本地模型时，推理可以留在本机或指定的局域网环境。

## 选择入口

| 需求 | 建议入口 |
| --- | --- |
| 图形化管理项目、会话和流程 | 桌面应用 |
| 服务器、脚本、自动化和远程终端 | 终端程序 |
| Android 上的轻量终端工作 | Termux 终端程序 |
