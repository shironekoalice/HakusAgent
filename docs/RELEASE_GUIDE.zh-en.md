# 版本与更新说明

HakusAI 的版本产物和变更说明以 [GitHub Releases](https://github.com/modemneko/HakusAgent/releases) 页面为准。

## 稳定版

稳定版适合日常使用，桌面应用可以从更新入口检查新版本，也可以手动下载对应平台的安装包。更新前会保留本机用户数据，但仍建议提前备份重要项目和配置。

## 测试版

测试版用于提前体验新功能，可能包含未完成的界面或平台适配。测试版与稳定版的更新渠道不同，不建议在重要工作环境中混用。

## 下载选择

- Windows：安装程序或 MSI。
- macOS：根据 Apple 芯片或 Intel 选择对应 DMG。
- Linux：根据发行版选择 deb 或 AppImage。
- Android：选择 arm64 APK。
- 终端：选择操作系统和 CPU 架构匹配的程序包。

遇到启动或更新问题时，请记录应用版本、操作系统、复现步骤和应用内诊断信息。不要在公开反馈中粘贴 API Key、访问令牌或完整的私有路径。
